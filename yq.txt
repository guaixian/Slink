一、上传与存储
- 上传方式：多图/拖拽/粘贴/URL 上传、上传预览/全屏预览、响应式布局适配移动端
- 存储策略：本地、AWS S3、阿里云 OSS、腾讯云 COS、七牛云、又拍云、SFTP/FTP/WebDAV/Minio；可配置路径命名规则、文件夹分类
- 数据库与缓存：MySQL/PostgreSQL/SQLite/SQL Server；Memcached/Redis 等缓存驱动，默认文件缓存

二、图片管理
- 基础操作：瀑布流展示、单选/多选、重命名、软删除、批量管理、右键菜单
- 外链与分享：一键复制外链、二维码链接、图片/相册分享（支持密码保护）
- 预览与查看：全屏预览、图片广场（画廊）、用户主页公开图片
- 空间与配额：全局/指定用户初始空间、上传频率限制、流量统计

三、图片处理
- 水印：文字/图片水印，支持平铺、位置/偏移/旋转设置，默认关闭
- 格式与尺寸：GD/Imagick 生成缩略图、裁剪、缩放；支持 JPG/PNG/GIF/WEBP 等
- 安全审核：集成阿里云/腾讯云/Nsfw.js 鉴黄，违规图片可删除或标记

四、权限与用户

- 角色组：多角色配置，绑定多存储策略，限制上传/审核/存储等权限
- 单用户/多用户：开放注册或单用户模式，IP 封禁（通配符）
- 安全控制：自定义链接参数、防盗链、接口 Token 认证（Bearer 前缀）

五、接口与开发
- API 能力：接口上传/管理图片/相册，支持第三方客户端对接（如 PicGo）
- 接口版本：v1 接口，含 token 认证、批量操作，便于封装请求参数
- 部署与升级：Docker 部署、OTA 在线升级、跨版本增量更新

六、安全与运维

- 安全机制：IP 封禁、水印防篡改、软删除、违规图片审核
- 运维工具：后台面板数据统计、筛选；队列任务处理耗时操作（如图片处理）

七、Pro+ 付费版专属
- 商业化：付费套餐、工单/订单/优惠券、支付宝/微信支付
- 高级分享：加密分享、用户主页、图片广场增强
- 云处理：滤镜、高级尺寸调整、批量水印；集成短信/邮件/站内公告

八、其他特性
- 主题与 UI：暗黑模式、自定义主题
- 实用功能：链接二维码生成、自定义链接参数、图片鉴黄、一键复制嵌入式代码
